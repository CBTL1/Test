Scopus Screening Results

Five-round AI-assisted screening of 321 Scopus records on virtual commissioning and digital twins.

Methodology

A semi-systematic literature review following Snyder (2019) was conducted to map the state of the art in virtual commissioning and digital twins for machine building. Scopus was searched on 24 November 2026, yielding 321 candidate records after deduplication.

Each record was screened against eight research questions: three primary questions on time savings (RQ1), fault detection (RQ2) and fidelity requirements (RQ3), and five thematic questions on scope and use (T1), model availability (T3), co-simulation (T4), X-in-the-loop testing (T5) and reconfigurability (T6). Ratings used a four-level scale: Yes, Partly, Mentions, or empty. A screening decision of Include, Maybe or Exclude was assigned based on the ratings.

To assess reliability, five independent screening rounds were run by an AI rater (Claude) with identical instructions but independent context. Each round processed all 321 records in four batches (81 + 81 + 81 + 78). The rating instructions (full prompt) were held constant across rounds. Inter-round agreement was measured using Fleiss’ κ, Cohen’s κ, Cochran’s Q and the Friedman test.

Overall screening agreement reached substantial levels (κ = 0.758), and the binary Include-vs-not decision reached almost perfect agreement (κ = 0.813). The Friedman test found no significant difference in ordinal ratings for any of the eight questions across rounds, while Cochran’s Q detected a small but significant variation in Include rates (Q = 15.26, p < 0.01).

How the Screening Was Run

The 321 Scopus records were exported as CSV and split into four batches (81+81+81+78). Five independent rounds were launched, each running four parallel AI agents (Claude) with identical instructions but no shared context. Each agent received one batch and returned a JSON file with ratings for every record. The 20 resulting JSON files (5 rounds × 4 batches) were validated, merged into Excel workbooks (one per round) and analysed for inter-rater agreement using Python (statsmodels, scipy).

The page itself was generated by a Python script that reads the CSV, computes sort order and DOI links, and emits the HTML.
